# GABA, el freno del cerebro

Web informativa y animada sobre el GABA (ácido γ‑aminobutírico), el principal neurotransmisor inhibidor del Sistema Nervioso Central.

Incluye:

- Modelo 3D animado de la molécula de GABA.
- La derivación del GABA (GABA shunt), con la ruta metabólica animada.
- Las regiones del encéfalo con más neuronas GABAérgicas.
- Una simulación de la sinapsis GABAérgica: liberación, receptores GABA‑A, entrada de cloruro y recaptación.
- Las acciones del GABA y las consecuencias del déficit y del exceso.

## Cómo verla

Abre `index.html` en cualquier navegador. Es un solo archivo, sin dependencias que instalar.
